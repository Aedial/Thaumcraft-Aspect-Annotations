# Thaumcraft Aspect Annotations

A client-side Thaumcraft 6 addon that adds the icon of the contained aspect to any Vis Crystal/Jar/Phial (or equivalent). It supports any item from other Thaumcraft addons that have aspects, as long as they are registered properly.

## Configuration

The mod includes a configuration file with an in-game GUI editor:

### Overlay Scale
The overlay scale determines the size of the aspect icon within the item slot. A scale of 1.0 means the icon will occupy the entire item slot.

### Overlay Position
The overlay position determines the location of the aspect icon within the item slot. The icon can be positioned in any corner or at the center. It will always render above the item, but you can play with transparency to customize the appearance.

### Overlay Transparency
The overlay transparency determines the transparency of the aspect icon within the item slot. 1.0 is fully opaque, and 0.0 is fully transparent.
